# Frontend — Students (Next.js)

See the main [README](../README.md) for how to run the API and the frontend together.

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_BASE_URL=http://localhost:8080
npm install
npm run dev                  # http://localhost:3000
```

HW1 docs (list screen, design check, code walkthrough) are in `docs/`. HW2 docs are in `../docs/`.
